# Fuzzing
Fuzzing is a tool that allows developpers to test their code with a huge amount of randomized inputs. It helps testing very niche and uncommon input to detect potential bugs in the codebase.

In go, this is a builtin tool, such as test or benchmark.
It test a function and output a report.
