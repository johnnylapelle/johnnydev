# What is TDD

`Test-Driven Development (TDD)` is a way to develop software.
The concept is simple:
- Write a unit test that fails.
- Write just enough code to pass that test.
- Refactor the test code and the production code.
- Repeat with another test case.

It's a way to have the assurance that your codebase passes all the tests you made.
